## 📌 各階段具體目標與規劃

### 階段 0：發音與五十音奠基（約 2～4 週）
* **核心目標**：看到假名能直覺發音、聽見能直覺寫出。
* **重點內容**：
  1. **平假名（ひらがな）**：用於日文固有詞、文法助詞。
  2. **片假名（カタカナ）**：**極度重要！** 旅遊菜單、商品名稱、外來語幾乎全是片假名。
  3. **特殊音**：濁音、半濁音、拗音（きゃ、しゅ等）、促音（っ）、長音。
  4. **基本發音規則**：高低音調（Accent）、輕音化現象。
* **推薦資源**：
  - App：《Drops 日語》、《五十音輕鬆學》、《Kana - Learn Hiragana & Katakana》
  - YouTube：出口日語（五十音教學）、秋山燿平（發音技巧）

---

### 階段 1：旅遊生存與基礎日常（N5 水準，約 2～3 個月）
* **核心目標**：**日本自由行無痛通關** + 日常生活基本打招呼與提問。
* **語法核心**：
  - 判定句：`～は～です`（我是...、這是...）
  - 核心助詞：`は` (主題)、`が` (主詞/對象)、`を` (受詞)、`に/で` (時間/地點/方式)、`の` (所有)
  - 動詞基本三大分類（第一類/第二類/第三類）與四大變形：
    - `ます形`（禮貌肯定/否定/過去）
    - `て形`（請求 `～てください`、正在進行 `～ています`）
    - `ない形`（禁止/不要 `～ないでください`）
    - `辭書形`（原形、能力 `～ことができます`）
* **四大場景實踐**：
  - ✈️ **旅遊**：機場出入境、飯店 Check-in/out、地鐵買票搭車、餐廳點餐加水結帳、藥妝店退稅。
  - 🎮 **休閒**：辨識動漫、日劇常見常用短句（ありがとう、ごめんなさい、助けて、すごい）。
* **推薦教材**：
  - 《大家的日本語 初級 I & II》或《出口仁：大家學標準日本語【初級本】》

---

### 階段 2：生活溝通與休閒沉浸（N4 ～ N3 水準，約 4～6 個月）
* **核心目標**：**在日生活自理** + **能看懂/聽懂 60%~70% 的休閒娛樂內容**。
* **語法核心**：
  - 動詞進階變形：可能形（會/能）、假定形（如果）、意向形（想要/打算）、被動形、使役形。
  - 授受動詞（あげる / もらう / くれる）：表達人際互動、人情往來關係。
  - 常用句型：因果推論、轉折、比較、推測（～かもしれない / ～そうです）。
* **四大場景實踐**：
  - 🏠 **生活**：超商/超市採購、郵局包裹、銀行開戶、生病看醫生敘述症狀、租屋詢問。
  - 🎮 **休閒**：開日文字幕看動漫與日劇、閱讀漫畫、看日本 YouTuber（生活 Vlog、遊戲實況）。
  - ✈️ **旅遊**：與民宿老闆深入聊天、向當地人詢問隱藏景點、遇到突發事件求助。
* **推薦教材**：
  - 《大家的日本語 進階 I & II》+ 《TRY！日本語 N3 達標！》

---

### 階段 3：職場敲門磚與流暢交流（N2 水準，約 6～9 個月）
* **核心目標**：**進入日商或日本職場工作** + **閱讀新聞/長篇小說**。
* **語法與文化核心**：
  - **敬語體系（極關鍵）**：
    - `丁寧語`（です / ます）
    - `尊敬語`（抬高對方動作，例如：いらっしゃる、召し上がる）
    - `謙讓語`（降低自己動作，例如：参る、いただく、申す）
  - 商務 Email 結構：前文季節問候、感謝語、主旨、本文、結語。
  - 抽象詞彙、邏輯論述與商務正式用語。
* **四大場景實踐**：
  - 💼 **工作**：日文履歷撰寫、面試自介、基本商業電話應答、會議意見表達。
  - 🏠 **生活**：市役所（區公所）手續辦理、契約簽訂、生活疑難排解。
* **推薦教材**：
  - 《新日檢完勝 500 題 N3~N2》、《TRY！日本語 N2》、《商務日語會話脫口說》

---

### 階段 4：高級商務與深度在地化（N1 / BJT，持續精進）
* **核心目標**：深度商務談判、公關演講、文化習俗與隱性溝通（空気を読む）。
* **實戰方向**：
  - BJT 商務日語能力考試準備。
  - 日本商業新聞（日本經濟新聞 Nikkei、NHK 專題）深度研讀。
  - 職場跨文化溝通與會議主持。

## ⏰ 上班族專屬：每日 15 分鐘「無痛微學習」時間表

上班已經很累，**「能長久堅持」遠比「一次讀很久」更重要**！每天只要 15 分鐘，無心理負擔：

| 步驟 | 時間 | 內容 | 方式 / 工具 |
| :--- | :--- | :--- | :--- |
| **Step 1: 熱身** | **5 分鐘** | 刷單字卡 / 假名 | 通勤或睡前，用手機或 Discord Bot 抽 1 題 `/quiz` 或看 `/daily` |
| **Step 2: 微吸收** | **7 分鐘** | 搞懂 1 個句型 | 每天只學 1 個概念（例如今天只學會「這多少錢？」或「請給我這個」） |
| **Step 3: 肌肉記憶**| **3 分鐘** | 開口跟讀 3 遍 | 照著音檔或拼音大聲念 3 次，讓嘴巴習慣發音肌肉記憶，立即下課！ |

> 🛋️ **週末放鬆模式**：
> 週末完全不碰課本！選一部喜歡的動漫、日劇或聽聽日文歌，躺在沙發上無壓力沉浸即可。

## 🛠️ 推薦工具箱

1. **查字典必備**：
   - `MOJI 辭書`（非常適合華人學習者，標註重音、例句完整）
   - `Weblio 日中中日辭典` / `コトバンク`（日日字典）
2. **單字記憶神器**：
   - `Anki`（間隔重複演算法 SRS，背單字必備）
3. **影音與沉浸**：
   - `Language Reactor`（Chrome 擴充套件，可在 Netflix / YouTube 顯示雙語字幕）
   - `NHK NEWS WEB EASY`（有注音假名與簡單日文的新聞網站，練閱讀最佳）

## 🌐 網頁版（GitHub Pages）

Discord bot 的所有學習功能已移植成靜態網站，放在 [`docs/`](docs/)，不需要伺服器，手機電腦都能用：

| 網頁區塊 | 對應 bot 指令 |
| :--- | :--- |
| 🏠 首頁 | `/hub` `/daily` `/omikuji` 冷知識 |
| ⚔️ 闖關 | `/quest` `/quest_reset` |

| 🎯 測驗 | `/quiz` `/review`（錯題本） |
| 🍜 會話 | `/scenario` `/chat`（角色扮演）`/katakana` |
| 🧩 文法 | `/grammar` |
| 🗣️ 跟讀 | `/voice` `/shadowing` |
| ✈️ 旅遊 | `/sos` `/culture` `/menu` `/drugstore` `/scan` |
| 🎌 / 🎐 / 📰 | `/anime`、公共領域「童謡・唱歌」、`/news`（`/lyrics` J-POP 僅保留在 Discord bot） |
| 📋 計畫 / 👑 我的 | `/plan` `/profile` |

網頁版獨有功能：

- 🃏 **單字卡間隔複習**：6 個牌組（五十音、闖關句子、情境會話、片假名、旅遊單字、新聞童謡單字），依記憶曲線排程，鍵盤空白鍵翻面、1～4 評分。
- 👨‍🏫 **何博士五十音學習法**：結合[何必日語](https://www.youtube.com/channel/UCZ5Wn4ss81cVKSk74Duv2BA)的教學重點（先背直行、再背橫行、用寫的、不用全背熟就進第一課），嵌入教學影片，並提供直行順序、行×段座標、米字格描寫三種練習。影片與習字帖版權屬何必日語。
- 🗓️ **每日挑戰**：每天全站同一組 5 題，做完可分享 ⭕❌ 成績、累積連續天數與學習熱力圖。
- 🎤 **發音評分**：用瀏覽器語音辨識幫跟讀打分數並標出念錯的字（Chrome / Edge）。
- 🧭 **新手引導**：首次進站選擇學習目標（旅遊／動漫／生活／工作），首頁顯示專屬路線。
- 📱 **可安裝 App**：支援加入主畫面與離線使用；分享網址會顯示預覽圖（圖示由 `tools/make_web_icons.py` 產生）。

- **語音**：改用瀏覽器內建日語語音（Edge / Chrome 效果最好）。
- **進度**：存在瀏覽器 localStorage，可在「我的」頁面匯出／匯入備份碼。
- **不支援**：定時推播（`/schedule`）與全服排行榜（`/leaderboard`）需要伺服器，仍由 Discord bot 負責。
